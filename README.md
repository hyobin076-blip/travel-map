# 🌍 국가별 여행지 안전 & 쿠키 스토리 맵

여행지별 혼잡 시간대, 낮/밤 안전도, 치안 메모와 함께 장소의 역사·특징을 담은 **쿠키 코멘트**를 기록하고 공유하는 Streamlit 웹 앱입니다.

## 주요 기능
- **국가별 게시판(탭):** 일본, 대한민국, 유럽, 동남아, 미주/기타 탭으로 정보 분류
- **여행지 정보 등록:** 작성자 닉네임, 장소명, 한적/혼잡 시간대, 낮/밤 안전도, 치안 메모 입력
- **🍪 쿠키 코멘트:** 장소가 유명한 이유와 역사적 배경 기록
- **로컬 DB 저장:** SQLite를 활용한 데이터 저장 및 삭제

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
